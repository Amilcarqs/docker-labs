# Soluciones de Docker Labs

Repositorio para documentar las soluciones de los laboratorios de Docker Labs, organizadas por nivel de dificultad.

## Estructura

- [`muy-facil/`](muy-facil/)
- [`facil/`](facil/)
- [`medio/`](medio/)
- [`dificil/`](dificil/)

Cada nivel contiene una carpeta `lab-template` como punto de partida. Cópiala, renómbrala con el nombre del laboratorio y documenta allí tu solución.

## Documentar un laboratorio

En el `README.md` de cada laboratorio, incluye el objetivo, los pasos realizados, los comandos utilizados y cómo comprobar y limpiar los recursos creados.
